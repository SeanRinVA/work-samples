# Stretch / Pass Decision Table (generic)

Purpose: reduce debate on edge-case roles. Use after the compensation and claim checks.

## Outcomes

| Outcome | Meaning | Resume? |
|---------|---------|---------|
| Apply | Core stack and conditions align | Yes |
| Stretch | One manageable gap; honest framing | Yes (name the gap) |
| Pass | Hard mismatch | No |

## Patterns

| Pattern | Default | Notes |
|---------|---------|-------|
| Core platform + remote + meets target | Apply | Primary lane |
| Same + adjacent domain | Apply | Stronger |
| Full ownership of a small-to-mid environment | Apply | Surface the ownership story |
| Implementation / deployment ownership | Apply or Stretch | Lead with the lifecycle work |
| Senior support, remote, meets target | Apply | Support is acceptable when the stack is real |
| Daily ownership of a tool with only fundamentals | Stretch or Pass | Depends on how hard the screen tests it |
| Required certification the person does not hold | Pass | Preferred is not the same as required |
| Clearance that must be obtained | Pass | Unless the person explicitly chooses to pursue it |
| Primary full-time below the walk-away | Pass | Unless tagged as supplemental |

## Stretch rules

A Stretch is valid only if:

1. Compensation is realistic.
2. There is exactly one primary gap.
3. The resume stays inside the claim boundaries.
4. The pattern has not already been declined.

Name the gap in the fit note so interview prep stays honest.

## Pass rules

- Person said Pass.
- Already applied with no material change.
- Clearance required that the person did not want to obtain.
- Role requires daily ownership of a tool that will be screened hard and is not verified.
- Relocation required.
- Primary full-time clearly under the walk-away.
