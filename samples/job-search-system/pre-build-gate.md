# Pre-Build Gate Checklist

Run this before any resume is drafted. If any item fails, stop.

## Compensation

- [ ] Target number confirmed for forms
- [ ] Lower bands treated as private math only
- [ ] Unlisted pay researched before scoring

## Claims

- [ ] Every planned bullet traces to a verified record
- [ ] No tool or depth beyond the claim boundaries
- [ ] Interview test: each bullet can be defended with a concrete example

## Already applied

- [ ] Checked tracker for prior application
- [ ] Material change exists if re-applying

## Fit

- [ ] Decision table outcome is Apply or Stretch
- [ ] Named gap (if Stretch) is acceptable
- [ ] No hard Pass factors

## Voice

- [ ] Draft will use plain language
- [ ] No language that cannot be explained in a screen

If the gate passes, the assistant may draft. The person still reviews before anything is submitted.
